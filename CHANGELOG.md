# Changelog

## 0.1.0 — London edition — 2026-09-11

Initial public PULSE release.

- London opportunity exploration across six business profiles and H3 resolutions 8 and 9.
- Explainable score components, confidence, editable weights, shortlists, shareable views, Site Battle and CSV/JSON exports.
- Typical-day transport playback, radial catchment evidence, source health and methodology.
- Seven real public-data adapters, immutable source provenance, spatial count models and validated atomic activation.
- Docker Compose startup, daily refresh worker, locked dependencies and independent CI.
- English and Simplified Chinese interface with persistent language selection; bilingual repository documentation.
- Product tour, reproducibility guide, recorded source/model manifest, benchmark conditions and responsive screenshots.

The recorded edition covers 33 boroughs and 119,514 business–cell scores. Historical source bytes are not included in the code release. Model caveats and performance limits are documented in the [verification report](docs/completion-report.md).
